产品定位声明

亲伴是“家庭陪护辅助工具”，核心功能包括日常视频通话、健康关爱、家庭相册推送、以及老人紧急情况下辅助通讯视频呼叫家人（产品界面中可能简称“SOS”，政策文档统一称“一键呼叫家人”）等。

本服务作为家庭陪护辅助工具，核心边界声明三条：

  1. 不是紧急救援设备，不承担救援责任
  2. 不替代任何政府公共服务热线——老人遭遇医学急症请第一时间拨打 120，治安事件请拨打 110，火灾消防请拨打 119
  3. 不评估老人状态、不做任何医学或安全判断——亲伴自身不含任何健康传感器、不测量任何生理数据，健康数据均由用户自行配置的第三方健康外设（如电子血压计、智能手环等）测得，亲伴仅作如实展示与通知。健康数据仅供家人参考，不构成医疗诊断依据；本产品不是医疗器械

三、四类敏感场景的特别保护

3.1 健康数据敏感保护

依据《中华人民共和国个人信息保护法》，健康数据被列为“敏感个人信息”，本服务承诺：

  1. 物理隔离存储：健康数据存储于独立的健康数据后端，与主业务数据库物理分离，独立的访问控制与审计日志
  2. 传输全程加密：使用业界标准加密协议（TLS 1.2 及以上）传输，防截获
  3. 最小化共享：健康数据仅在家庭群内可见，向任何第三方共享前，必须再次获得您的明示同意
  4. 您的删除权：您可随时在子女端 App 中申请永久删除全部历史健康数据，删除请求 7 天内执行

  5. 健康数据异常通知边界：当老人健康数据超出家人在 App 中自行设定的关注范围时，系统仅将该客观数据事实通过家庭群消息推送给家人（同时触发推送 ＋ 可选地由老人主动发起一键呼叫家人）。家人收到通知后，完全由家人自主判断是否致电老人 / 拨打 120 / 联系医生。

    本服务的健康数据通知机制采用“家人自定义阈值触发”方式，系统仅执行数值比对逻辑，不对老人健康状态作出任何评估或判断结论。该机制的设计目的在于：通知家人关注老人所测量的客观数据，由家人自主做出后续判断。本服务不向家人或老人输出任何医学结论或行为建议。

  6. 🔴 产品定位强声明：亲伴产品自身不含任何健康或医疗传感器，不测量、不采集任何生理健康数据。所有健康数据均来源于用户自行选购、配置的第三方蓝牙健康外设（如电子血压计、智能手环、血氧仪等），由该等外设测量后经“健康关爱”App 读取上传。亲伴的健康关爱功能仅是将外设测得的数据如实展示给家人、并在数据异常时通知家人，不提供任何医疗相关措施（不诊断 / 不治疗 / 不给医疗建议 / 不替代医生），也不对健康数据作任何加工、解读或评估。健康数据的测量及其准确性由相应外设及其生产厂商负责，亲伴不对外设数据的准确性作任何保证。健康数据仅供家人参考，不构成医疗诊断依据。本产品不是医疗器械。任何健康异常请咨询专业医生，必要时拨打 120
  7. 健康数据收集的单独同意机制：
    • 首次连接配套蓝牙血压计等设备时，App 会单独弹窗（独立于本隐私政策整体同意），明确告知“我们将收集您家中老人的血压/心率等健康数据用于向家人展示”
    • 您可仅同意此项而不必同意其他可选项；也可仅拒绝此项而不影响其他功能使用
    • 同意后可随时撤回。撤回后我们将停止收集新的健康数据；对于已收集的历史健康数据，默认保留（您可随时申请删除），或您在撤回时可同时勾选“同时删除全部历史数据”选项

3.2 一键呼叫家人功能边界

关键说明：亲伴的“一键呼叫家人”功能（在产品界面中可能简称为“SOS”，政策文档统一称“一键呼叫家人”）本质是老人主观感觉需要联系家人时，通过一键操作快速发起视频通话给所有绑定家人的辅助通讯工具。

本功能：

  • 不是紧急救援设备，不承担救援责任
  • 不替代任何政府公共服务热线（120 / 110 / 119）
  • 不评估老人是否处于危险状态、不做任何医学或安全判断

如老人遭遇医学急症、治安事件、火灾等真实紧急情况，请第一时间拨打 120 / 110 / 119。亲伴的“一键呼叫家人”是辅助通知家人的视频通话工具，不能替代上述任何政府急救热线。

本服务承诺：

  1. 位置数据仅在一键呼叫家人时短暂收集（§2.5 已述，日常完全不追踪）
  2. 一键呼叫产生的视频通话不录制（与 §2.3 一致）
  3. 子女完整自主权：子女端永远拥有“接通”与“拒接”的完整自主权，本服务绝不强制自动接听，也绝不向任何第三方（包括但不限于社区、物业、医院、急救机构）自动转接呼叫

3.3 老年用户特别保护

本产品的最终用户群体包含大量 59 岁以上的老年人，我们承诺：

  1. 老人 TV 端无独立账号注册：由子女在手机端代为完成
  2. 老人无需阅读复杂条款：本政策由子女在手机端阅读同意；TV 端仅展示简洁版功能告知（§1.1 分层告知同意框架）
  3. 老人无定向广告风险：本服务不展示任何商业广告（包括预装第三方 App 的广告）
  4. 老人误操作保护：涉及费用或安全影响的操作（解绑、删除）必须由子女在手机端确认；老人端无任何“扣费按钮”
  5. 老人健康数据由子女控制：访问、共享、删除权限默认由主绑定人（子女）行使

3.4 音视频通话边界

  1. 仅在通话时采集（§2.8）
  2. MVP 阶段不录制（§2.3）
  3. 媒体流主走直连模式：仅在直连失败时通过第三方音视频服务兜底（兜底模式下媒体流加密透传）

附录 E：用户常见问题（FAQ）

E1. 如何注销我的账号？

子女端 App “我的”→“账号与安全”→“注销账号”；按引导确认后，30 天内永久删除您的全部个人信息（法定保留期内的财税记录除外）。

E2. 如何删除我的全部数据（不注销账号）？

子女端 App “我的”→“隐私设置”→“删除数据”→选择数据类别（健康数据 / 通话记录 / 一键呼叫家人记录 等）；提交后 7 个工作日内执行。

E3. 我家老人去世了，数据怎么处理？

请通过 §九 客服微信或客服电话联系我们，主绑定子女可申请：

  • 账号转为归档状态（默认，健康历史保留 3 个月）
  • 立即删除全部数据（7 个工作日内执行）
  • 导出全部数据后再删除（用于留念）

E4. 我换手机了，数据会丢吗？

不会。所有数据存储在我方服务器，您只需在新手机上用同一手机号登录子女端 App，所有数据自动同步。

E5. 我把设备卖给别人，需要做什么？

出售前必须先在子女端 App 解绑设备：“我的”→“我的设备”→选择设备→“解绑”。解绑后：

  • 设备绑定关系立即移除
  • 设备数据 90 天内清除
  • 新使用者重新绑定时，与原数据无任何关联，完全隔离

E6. 老人不会用手机，他自己怎么知道隐私政策内容？

依据《老年人友好型 App》要求，我们采用“分层告知同意”框架：

  • 老人端只展示最简洁的核心层告知（我们收集什么 / 用来做什么 / 发给谁）
  • 完整版本由子女在子女端 App 阅读同意，代行知情同意权

E7. 一键呼叫家人（SOS）按错了怎么办？

完全可逆。所有家人手机会收到呼叫，任一家人接通后您可立即说明“按错了”挂断即可。子女端永远拥有拒接/挂断的完整自主权，我们绝不强制接听。

E8. 健康数据会被卖给保险公司吗？

绝对不会。健康数据仅在家庭群内可见，永不共享给任何第三方平台（包括但不限于保险公司、医院、养老机构、广告平台）。任何第三方共享必须再次获得您的明示同意。

E9. 数据存在国内还是国外？

全部存储在中华人民共和国境内。所有第三方 SDK（声网、推送、高德、百度等）均使用国内节点，无任何数据跨境传输。

E10. 我对隐私政策有异议怎么办？

通过 §九 任一渠道联系我们，7 个工作日内响应。同时您可向以下监督机构投诉：

  • 国家网信办举报中心：https://www.12377.cn
  • 工信部投诉受理中心：12321
  • 消费者保护：12315
